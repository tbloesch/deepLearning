\textbf{Observations:}
\begin{itemize}
    \item No augmentation improves validation loss or accuracy beyond seed-to-seed variation
          (val = 134 images, so one image = 0.75 pp).
    \item Crop and all lower the training accuracy (less memorisation), but this does not
          carry over to validation. All has a slightly higher val loss than none (about 2.5 std).
    \item Crop and all converge more slowly (val loss slightly higher from epoch 3 to 15 in the
          comparison plot); with a fixed 20 epochs they may be disadvantaged $\rightarrow$ limitation.
    \item Likely reason: the ImageNet V2 weights were trained with flip/crop/photometric augmentation,
          so the frozen features are already largely invariant; only the linear head can adapt.
          \emph{TODO: cite the torchvision IMAGENET1K\_V2 training recipe.}
\end{itemize}
\textbf{Decision:} pairs of augmentations skipped (all behaves like crop plus a little more).
Test whether augmentation matters once the features can change $\rightarrow$ Exp 3.

\subsection*{Reproducibility check}
\textbf{Setup:} Exp 1b (ResNet-50, frozen, no augmentation, seeds 0/1/2) trained a second time to
get its histories for the comparison plot.\\
\textbf{Result:} identical to Exp 1b to four decimals for every seed
(best epochs 20/19/20; val loss $0.3575 \pm 0.0038$; val acc $88.81 \pm 0.75$\%).\\
\textbf{Decision:} seeding works; GPU non-determinism did not occur. Mention in Methods.

\subsection*{Exp 3 -- Fine-tuning \texttt{layer4}}
\textbf{Design:} $2 \times 2$: \{frozen, \texttt{layer4} unfrozen\} $\times$ \{none, all\}, ResNet-50,
20 epochs, seeds 0/1/2, fresh model for every configuration.\\
\textbf{Code changes:}
\begin{itemize}
    \item \texttt{build\_model(..., unfreeze\_layer4=False)}: freezes everything, then sets
          \texttt{requires\_grad=True} for \texttt{layer4}.
          Trainable parameters: frozen 14{,}343 / 23{,}522{,}375 (0.06\%);
          \texttt{layer4} unfrozen 14{,}979{,}079 (63.7\%).
    \item \texttt{train(..., backbone\_lr=None)}: Adam parameter groups, \texttt{layer4} with
          lr $= 10^{-4}$, everything else (\texttt{fc}) with lr $= 10^{-3}$. \texttt{None} = one group as before.
    \item Notebook: one settings cell; \texttt{RUN\_NAME} in all file names
          (\texttt{resnet50\_layer4\_\{aug\}} vs.\ \texttt{resnet50\_frozen\_\{aug\}}), so nothing is overwritten.
\end{itemize}

\textbf{Observations:}
\begin{itemize}
    \item Unfreezing \texttt{layer4} is a large effect: val loss $0.3575 \rightarrow 0.2324$ ($-35\%$),
          val acc $88.81 \rightarrow 93.03\%$ (+4.2 pp, about 6 images). Val acc ranges do not overlap
          (frozen 88.1--89.6\%, \texttt{layer4} 91.8--94.0\%).
    \item Memorisation within 3--4 epochs (train loss $\approx 0$, train acc 100\%). Val loss plateaus after
          epoch 3 and drifts up slowly; seed 2 (none) and seed 1 (all) show clear overfitting (U-shape).
    \item Much noisier: val loss std $0.0038 \rightarrow 0.0239$ (none) / $0.0576$ (all), best epochs vary
          (3/19/8 and 13/7/8). Best-epoch values lie below the mean curve $\rightarrow$ selection bias,
          the reported val numbers are optimistic. Test set gives the unbiased estimate.
    \item Val loss and val acc disagree after epoch 3 (loss flat/rising, acc slightly rising): the model becomes
          overconfident on its remaining errors. Kept val loss as the pre-defined criterion.
    \item Augmentation does not help with \texttt{layer4} unfrozen either: val loss $0.2324$ vs.\ $0.2161$
          (difference $\ll$ std), val acc identical. Mean val loss over epochs 5--20 (less affected by
          selection): none $0.289 \pm 0.034$, all $0.286 \pm 0.063$. Augmentation keeps train loss higher
          (epoch 20: 0.0005 vs.\ 0.0144) but this does not carry over to validation.
    \item 2$\times$2 conclusion: large main effect of unfreezing, no effect of augmentation in either row,
          no interaction. The Exp 2 hypothesis (augmentation only failed because the backbone was frozen)
          is \emph{not} supported.
\end{itemize}
