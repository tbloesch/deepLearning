\subsection*{Exp 2 -- Data augmentation (ResNet-50, frozen backbone)}
\textbf{Setup:} arch = resnet50, frozen backbone (only \texttt{fc} trains, 14{,}343 parameters),
20 epochs, Adam lr = $10^{-3}$, batch size 32, seeds 0/1/2. Augmentation on the training set only
(val unchanged). Best epoch selected by validation loss.\\
\textbf{Configurations:}
none;
flip = \texttt{RandomHorizontalFlip};
crop = \texttt{RandomResizedCrop(224, scale=(0.7, 1.0))} instead of \texttt{Resize};
jitter = \texttt{ColorJitter(brightness=0.2, contrast=0.2)} (no hue/saturation: coat colour is a breed feature);
all = flip + crop + jitter.\\
\textbf{Checkpoints:} \texttt{resnet50\_frozen\_\{aug\}\_seed\{0,1,2\}.pt},
histories \texttt{resnet50\_frozen\_\{aug\}\_histories.json} (Drive + \texttt{results/}).

\textbf{Observations:}
\begin{itemize}
    \item No augmentation improves validation loss or accuracy beyond seed-to-seed variation
          (val = 134 images, so one image = 0.75 pp).
    \item Crop and all lower the training accuracy (less memorisation), but this does not
          carry over to validation. All has a slightly higher val loss than none (about 2.5 std).
    \item Crop and all converge more slowly (val loss slightly higher from epoch 3 to 15 in the
          comparison plot); with a fixed 20 epochs they may be disadvantaged $\rightarrow$ limitation.
    \item Likely reason: the ImageNet V2 weights were trained with flip/crop/photometric augmentation,
          so the frozen features are already largely invariant; only the linear head can adapt.
          \emph{TODO: cite the torchvision IMAGENET1K\_V2 training recipe.}
\end{itemize}
\textbf{Decision:} pairs of augmentations skipped (all behaves like crop plus a little more).
Test whether augmentation matters once the features can change $\rightarrow$ Exp 3.

\subsection*{Reproducibility check}
\textbf{Setup:} Exp 1b (ResNet-50, frozen, no augmentation, seeds 0/1/2) trained a second time to
get its histories for the comparison plot.\\
\textbf{Result:} identical to Exp 1b to four decimals for every seed
(best epochs 20/19/20; val loss $0.3575 \pm 0.0038$; val acc $88.81 \pm 0.75$\%).\\
\textbf{Decision:} seeding works; GPU non-determinism did not occur. Mention in Methods.
