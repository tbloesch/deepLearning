% Unfreezing layer4 was the only change that clearly improved performance
% (Table~\ref{tab:exp3}, Figure~\ref{fig:exp3}): validation loss decreased by 35\% and validation
% accuracy increased by 4.2 percentage points, with no overlap between the seed ranges.
% Augmentation had no measurable effect in either setting. To limit the influence of selecting a
% single noisy epoch, we also compared the mean validation loss over epochs 5--20, which was likewise
% equal ($0.289 \pm 0.034$ without and $0.286 \pm 0.063$ with augmentation).
% With layer4 unfrozen, the model memorised the training set within 3--4 epochs, the validation
% curves became considerably noisier, and the selected epoch varied between seeds (3, 19 and 8)
% (Figure~\ref{fig:exp3-curves}). This contradicts our hypothesis from Experiment~2 that augmentation
% was ineffective only because the backbone was frozen.
